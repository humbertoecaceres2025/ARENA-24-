# FM Arenas Online — ARENA 24

Paquete listo para publicar como sitio estático en GitHub Pages / github.io.

## Antes de subir
1. Abrí `js/app.js`.
2. Reemplazá `PEGAR_AQUI_LA_URL_DEL_STREAM_ZENOMEDIA` por la URL pública de reproducción de tu AutoDJ/stream de ZenoMedia.
3. Si querés, cambiá los enlaces de Facebook e Instagram en `index.html`.

## Publicar en GitHub Pages
Subí todo el contenido de esta carpeta al repositorio que usa tu `github.io`.
El archivo `index.html` debe quedar en la raíz publicada.

## Estructura
- `index.html` — página principal
- `css/style.css` — diseño responsive
- `js/app.js` — reproductor y compartir
- `audio/` — carpeta reservada para IDs/promos si luego querés agregarlos
- `assets/` — logos, imágenes y recursos

La web no contiene una URL de streaming inventada: queda preparada para conectar directamente tu stream real.
